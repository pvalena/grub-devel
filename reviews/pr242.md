## Additional findings

The diff hides that the old string already began with a literal form feed (bytes checked: `"\f\e[2J"`); the patch
swaps it for the identical `\x0c` escape, so the only runtime change is the trailing `\e[m` (SGR reset). The string
has no `%`, so `grub_terminfo_tparm()` copies it verbatim. The `ieee1275` type is used by the console on all
IEEE1275 platforms (i386, sparc64, powerpc), not only ppc. `setcolor` is set for this type, so nothing else emits
`\e[m`; text printed after a clear and before the next `setcolorstate` (banner in `grub_normal_init_page()`, prompt
after `clear`) now uses terminal-default colors, not `color_normal`. Matches the stated intent; not tested on firmware.
