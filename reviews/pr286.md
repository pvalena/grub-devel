# AI Review: MR !286 - util/grub-mkimagexx: Validate ELF section bounds

1 commit hardens `grub_mkimage_load_image()` against malformed ELF kernel/module inputs: rewrites
the section-header-table bounds check to avoid an addition overflow, range-checks `e_shstrndx`,
and adds a loop validating `sh_offset`/`sh_size` (plus entry size and `sh_link`/`sh_info`) for
every section whose type is not `SHT_NOBITS`.

**Commits:**
1. **9fa459f22** - util/grub-mkimagexx: Validate ELF section bounds

## Issues Found

### Issue 1: SHT_NOBITS lets an index-targeted section skip offset/size validation

**Location:** `util/grub-mkimagexx.c`, three sites: `grub_mkimage_load_image()` (~lines
2536-2539), `relocate_symbols()` (~lines 658-661), `arm_get_trampoline_size()` /
`get_symbol_address()` (~lines 795-798, 725-733)

The new validation loop only checks a section's `sh_offset`/`sh_size` when that section's own
`sh_type != SHT_NOBITS`. Several places resolve "the section named by this already-range-checked
index" (`e_shstrndx`, or a section's `sh_link`) and dereference that target's `sh_offset`
unconditionally, without checking the target's own type. A crafted file can give the section that
`e_shstrndx` (or a symtab's/REL's `sh_link`) points at `sh_type = SHT_NOBITS` with an arbitrary
`sh_offset`, bypassing the new check entirely:

```c
s = (Elf_Shdr *) ((char *) smd.sections
                    + grub_target_to_host16 (e->e_shstrndx) * smd.section_entsize);
smd.strtab = (char *) e + grub_host_to_target_addr (s->sh_offset);   /* s->sh_offset untrusted */
```

The resulting wild pointer (`smd.strtab`, or `symtab`/`symtab_section` at the other two sites) is
then read as a C string via `strcmp`/`strncmp` (`is_kept_reloc_section()`, `put_section()`,
`relocate_symbols()`'s `__bss_start`/`_end` comparisons) or dereferenced as an `Elf_Sym` in
`get_symbol_address()` — an out-of-bounds read against attacker-controlled offsets, exactly the
bug class this commit's own message says it closes.

**Draft fix** — require the expected section type at each dereference site (a real string/symbol
table is never `SHT_NOBITS`, so this composes correctly with the existing loop, which has already
validated every non-`SHT_NOBITS` section's offset/size by the time these sites run):

```diff
--- a/util/grub-mkimagexx.c
+++ b/util/grub-mkimagexx.c
@@ grub_mkimage_load_image()
   s = (Elf_Shdr *) ((char *) smd.sections
 		      + grub_target_to_host16 (e->e_shstrndx) * smd.section_entsize);
+  if (grub_target_to_host32 (s->sh_type) != SHT_STRTAB)
+    grub_util_error (_("invalid string table in %s"), kernel_path);
   smd.strtab = (char *) e + grub_host_to_target_addr (s->sh_offset);
```

```diff
--- a/util/grub-mkimagexx.c
+++ b/util/grub-mkimagexx.c
@@ relocate_symbols()
   symtab_section = (Elf_Shdr *) ((char *) smd->sections
 				 + grub_target_to_host32 (smd->symtab->sh_link)
 				   * smd->section_entsize);
+  if (grub_target_to_host32 (symtab_section->sh_type) != SHT_STRTAB)
+    grub_util_error ("%s", _("invalid string table for symbol table"));
   symtab = (char *) e + grub_target_to_host (symtab_section->sh_offset);
```

```diff
--- a/util/grub-mkimagexx.c
+++ b/util/grub-mkimagexx.c
@@ arm_get_trampoline_size()
 	symtab_section = (Elf_Shdr *) ((char *) sections
 					 + (grub_target_to_host32 (s->sh_link)
 					    * section_entsize));
+	if (grub_target_to_host32 (symtab_section->sh_type) != SHT_SYMTAB
+	    && grub_target_to_host32 (symtab_section->sh_type) != SHT_DYNSYM)
+	  grub_util_error ("%s", _("invalid symbol table for relocation section"));
```
