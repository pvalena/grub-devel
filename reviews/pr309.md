## Additional findings

Adds four bounds checks in grub_net_recv_ethernet_packet() to prevent buffer overruns when
parsing truncated or crafted packets:

1. Base Ethernet header (sizeof(*eth)) before reading ethertype
2. VLAN extension (etherhdr_size + 4) when VLAN tag detected
3. LLC header (sizeof(*llch)) when type <= 1500
4. SNAP header (sizeof(*snaph)) after pulling LLC header

Each check drops the packet cleanly (grub_netbuff_free + return GRUB_ERR_NONE) rather than
reading uninitialized memory. The checks are properly ordered: each header access is guarded
by a preceding length verification.
