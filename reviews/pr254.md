## Additional findings

Adds in-place verification to reduce peak memory usage for large initrds. Defers TPM/TPCM measurement until
after the file is loaded, avoiding a second copy in memory. Key safety mechanisms: VERIFY_IN_PLACE requires
NO_DECOMPRESS (enforced at open, prevents hash mismatch compressed vs decompressed bytes); authentication
verifiers never deferred (only measurement); unverified data cannot reach kernel (entire target buffer wiped
on failure). AI-assisted code shows good defensive programming: buffer wipe, proper error propagation, debug
warnings, no TOCTOU between load and verify.
