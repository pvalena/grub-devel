  leaves retries >= 0 (no warning); 10 failures end with retries == -1 -> warning. Only EBUSY (already frozen)
  returns 0 -> retried; other errors return 1 (EOPNOTSUPP/ENOSYS/EPERM silently, others warn).
- linux/journaled_fs.c: opens `grubdir` O_RDONLY (directory fd is valid for FIFREEZE/FITHAW), freeze loop retries only
  on EINTR for up to 3 s (signals are blocked, so effectively once), thaw loops on EINTR, fd closed on every path
  after open (the early `return 1` happens before the signal mask changes). In the default layout nothing
  writes to the frozen filesystem between freeze and thaw (only ioctl(FITHAW) on the open fd). The thaw-failure
  warning (grub_util_warn) is emitted before the signal mask is restored, while the fs may still be frozen.
  grub_get_time_ms exists in emu (grub-core/kern/emu/misc.c:169); grub_sleep is in include/grub/time.h.
- Makefile.util.def: new sources are in the grub-install program block only (the only user); osdep wrapper

  are set at lines 140-148; make_system_path_relative_to_its_root comes from grub-mkconfig_lib (sourced at line 52).
