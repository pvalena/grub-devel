## Additional findings

- `create` no longer triggers the probe (it calls `grub_util_create_envblk_file` directly, not
  `open_envblk_file`). Not a regression: that function (util/editenv.c) never consults `fs_envblk`.
- `list`/`set`/`unset` all call `open_envblk_file` first, so `fs_envblk` is populated before the later
  block-write path uses it; ordering matches the old main()-level probe.
- Probing after `open_envblk_file` (which implicitly creates the file) lets realpath succeed on first run,
  where the old pre-create main() probe could not; canonicalization also now matches symlink/relative
  spellings of DEFAULT_ENVBLK_PATH. Strict improvement.
- `free()` on `grub_canonicalize_file_name` results is correct (xmalloc/realpath-backed); the static
  `probed` guard is fine since `open_envblk_file` runs once per invocation.
