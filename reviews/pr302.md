# AI Review: MR !302 - Menu entry audible indication (accessibility)

3 commits add audible feedback for blind users navigating the GRUB menu: a hook infrastructure
that fires when a menu entry gets focus, an implementation in the play module that beeps N+1
times for entry N (cycling through configurable frequencies from the `menu_tones` variable), and
grub-mkconfig integration that loads the play module and sets `menu_tones` when
`GRUB_MENU_TONES` is configured in `/etc/default/grub`. The feature is opt-in (silent by default)
and x86-only (PC speaker).

**Commits:**
1. **faef0ee3c** - normal/menu: Add a hook called when a menu entry gets the focus
2. **fdd6dad69** - play: Indicate the focused menu entry by a series of beeps
3. **2b15369e2** - mkconfig: Add GRUB_MENU_TONES to indicate the focused menu entry by beeps

## Additional findings

Traced the implementation from menu navigation through hook invocation to beep generation:
`menu_set_chosen_entry` and `menu_init` call the hook when an entry is selected or when the menu
first displays (commit 1). The play module's `indicate_menu_entry` hook parses `menu_tones` into
a fixed-size array (no allocation, no file access), validates each frequency is 20-20000 Hz, and
caps the beep count at 16 to keep the menu responsive (commit 2). The grub-mkconfig integration
validates `GRUB_MENU_TONES` contains only digits and spaces before injecting it into grub.cfg,
preventing arbitrary content injection; the generated code checks `grub_cpu` is i386/x86_64 before
loading the play module, correctly limiting the feature to platforms with a PC speaker (commit 3).
Error handling preserves `grub_errno` across the hook (parsing failures don't leak into the global
error state), and the module cleans up the hook pointer in `GRUB_MOD_FINI` with a guard to avoid
clearing a hook installed by a different module. The validation/parsing split (mkconfig is more
restrictive, play module uses `grub_isspace`) is intentional: mkconfig ensures only safe characters
reach grub.cfg, while the play module's permissiveness with other whitespace is unreachable from
the mkconfig path.
