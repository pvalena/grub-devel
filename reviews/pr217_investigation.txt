== Build Integration (CPPFLAGS_ZSTD) ==

CPPFLAGS_ZSTD is defined in conf/Makefile.common and applied in both
Makefile.core.def (module build) and Makefile.util.def (libgrubmods.a).

Three flags:

1. -DZSTD_DISABLE_ASM=1
   portability_macros.h checks: if !defined(ZSTD_DISABLE_ASM) && ...
   then ZSTD_ENABLE_ASM_X86_64_BMI2=1. The flag prevents this, which
   is correct because huf_decompress_amd64.S is not imported.

2. -D_GNU_SOURCE=1
   config.h.in line 71 defines _GNU_SOURCE as 1. zstd_deps.h line 35
   does a bare "#define _GNU_SOURCE" (no value). Without predefining
   it, both would be active with different forms, causing a compiler
   warning or error depending on the toolchain. Predefining with =1
   makes zstd_deps.h's "#if !defined(_GNU_SOURCE)" test false, so the
   bare define is skipped.

3. -DZSTD_TRACE=0
   zstd_trace.h line 43: "#define ZSTD_TRACE ZSTD_HAVE_WEAK_SYMBOLS"
   would enable tracing on ELF platforms with GCC. The GRUB module
   loader cannot resolve undefined weak symbols, so genmoddep.awk
   would reject the module. Setting ZSTD_TRACE=0 makes the "#ifndef
   ZSTD_TRACE" on line 42 take the predefined value, skipping the
   weak symbol declarations.
