## Issues Found

### Issue 1: `conf/Makefile.extra-dist` still lists the four deleted gnulib patches, so `make dist` fails

**Location:** `conf/Makefile.extra-dist`, lines 33-36 (left behind by commit 5, `326d5c0df`)

Commit 5 deletes `fix-dropped-const.patch`, `fix-regcomp-resource-leak.patch`, `fix-regexec-resource-leak.patch`
and `fix-gcc-15-compile.patch`, and drops them from the `patch` loop in `bootstrap.conf`. Their
`EXTRA_DIST += grub-core/lib/gnulib-patches/...` entries stay in `conf/Makefile.extra-dist`, which `Makefile.am:11`
includes. Automake needs every `EXTRA_DIST` file to exist, so `make dist` would stop with a "No rule to make
target ... needed by distdir" error (standard automake behaviour; exact wording varies by version; a scratch
automake project with an absent `EXTRA_DIST` file stopped this way, GRUB's own `make dist` was not run).
The release job (`.gitlab-ci/script/create-artifacts.sh:54`, `set -xeu`, tag pipelines only) runs `make dist`, so
the failure would show up at release time, not on MR pipelines or a normal build/check.

**Draft fix** -- remove the four stale entries (fold into commit 5):

```diff
--- a/conf/Makefile.extra-dist
+++ b/conf/Makefile.extra-dist
@@ -30,10 +30,6 @@
 EXTRA_DIST += grub-core/genemuinitheader.sh
 
 EXTRA_DIST += grub-core/lib/gnulib-patches/fix-width.patch
-EXTRA_DIST += grub-core/lib/gnulib-patches/fix-dropped-const.patch
-EXTRA_DIST += grub-core/lib/gnulib-patches/fix-regcomp-resource-leak.patch
-EXTRA_DIST += grub-core/lib/gnulib-patches/fix-regexec-resource-leak.patch
-EXTRA_DIST += grub-core/lib/gnulib-patches/fix-gcc-15-compile.patch
 EXTRA_DIST += grub-core/lib/gnulib-patches/fix-unused-value.patch
 
 EXTRA_DIST += grub-core/lib/libgcrypt-patches/01_md.patch
```
