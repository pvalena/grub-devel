## Additional findings

1. **LV size overflow** (grub-core/disk/lvm.c:701): Replaces unchecked
`lv->size += seg->extent_count * vg->extent_size` with grub_mul() and grub_add() from
safemath.h. Prevents integer overflow from crafted metadata that would wrap lv->size and
lead to truncation/OOB reads.

2. **RAID segment OOB read** (line 922): Changes `if (q == mda_end)` to `if (q >= mda_end)`.
The loop `while (q < mda_end && *q != '"')` can leave q at mda_end when no closing quote is
found; the >= check safely catches this.

3. **RAID device count validation** (line 874): Rejects seg->node_count == 0 (prevents
allocation of zero-size array) and seg->node_count < 2 for RAID4 (prevents underflow in
`grub_memmove(..., seg->node_count - 1)` at line 933).

4. **PV UUID cleanup order** (line 531): Swaps grub_free(pv->id.uuid) and grub_free(pv->name)
to match LIFO allocation order (name allocated first at line 491, uuid second at line 503).
Ensures uuid is freed when validity parsing fails after uuid allocation.
