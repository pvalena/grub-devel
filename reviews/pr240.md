# AI Review: MR !240 - Rework linux,linux16 commands

1 commit refactors i386 Linux loaders to allocate a single buffer for the entire kernel image to enable TPM
measurement, replacing multiple file reads with one full-file read followed by memcpy operations.

**Commits:**
1. **074a8aa23** - Rework linux,linux16 commands

## Issues Found

### Issue 1: Missing underflow check causes buffer over-read in linux.c

**Location:** `grub-core/loader/i386/linux.c`, lines ~757, 1049

The refactoring removes the implicit bounds check that `grub_file_read()` provided. The old code would fail if
the file was shorter than the headers claimed; the new code blindly copies from the buffer without checking.

The calculation `prot_file_size = grub_file_size(file) - real_size - GRUB_DISK_SECTOR_SIZE` can underflow if
`real_size + GRUB_DISK_SECTOR_SIZE > file_size`, producing a huge unsigned value. Then
`grub_memcpy(prot_mode_mem, kernel + kernel_offset, prot_file_size)` reads far past the end of the `kernel`
buffer (and may overflow `prot_mode_mem` if `prot_file_size > prot_size`).

The sister file `grub-core/loader/i386/pc/linux.c` correctly uses `grub_sub()` to detect underflow (lines
222-223), but `linux.c` does not.

**Consequence:** A crafted kernel image with large `setup_sects` (but below `GRUB_LINUX_MAX_SETUP_SECTS`) and
small actual file size triggers unsigned underflow, causing a buffer over-read that could crash GRUB or leak
memory contents.

**Draft fix** -- add underflow detection like pc/linux.c does:

```diff
--- a/grub-core/loader/i386/linux.c
+++ b/grub-core/loader/i386/linux.c
@@ -754,7 +754,13 @@ grub_cmd_linux (grub_command_t cmd __attribute__ ((unused)),
     setup_sects = GRUB_LINUX_DEFAULT_SETUP_SECTS;
 
   real_size = setup_sects << GRUB_DISK_SECTOR_BITS;
-  prot_file_size = grub_file_size (file) - real_size - GRUB_DISK_SECTOR_SIZE;
+  if (grub_sub (grub_file_size (file), real_size, &prot_file_size) ||
+      grub_sub (prot_file_size, GRUB_DISK_SECTOR_SIZE, &prot_file_size))
+    {
+      grub_error (GRUB_ERR_OUT_OF_RANGE, N_("overflow is detected"));
+      goto fail;
+    }
```
