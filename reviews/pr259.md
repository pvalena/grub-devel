## Additional findings

`argp_doc()` declares `const char *doc` (from `dgettext`) and previously assigned
`char *vt = strchr (doc, '\v');`. `vt` is only ever used for pointer arithmetic and truth
tests (`vt + 1`, `vt - doc`, `vt ?`) feeding `const char *inp_text`/`size_t inp_text_limit` -
never written through or passed where a mutable `char *` is required - so retyping it to
`char const *vt` is behavior-preserving and correctly resolves the warning. The new
`fix-dropped-const.patch` follows the exact header convention (`a/lib/...`, `b/lib/...`) used
by the existing sibling patches (e.g. `fix-width.patch`), and is wired up the same way: added
to the `patch -d grub-core/lib/gnulib -p2` loop in `bootstrap.conf` and to
`conf/Makefile.extra-dist`. Both wiring points are present and consistent with the established
pattern for the other five patches applied in the same loop.
