## Additional findings

Three security fixes for malformed HFS filesystem images:

1. **Recursive extent lookup prevention**: Rejects extent overflow lookups for the Extents
Overflow file itself (GRUB_HFS_CNID_EXT), preventing unbounded stack growth from recursive calls
between grub_hfs_block(), grub_hfs_find_node(), and grub_hfs_iterate_records().

2. **Extent progress validation**: Ensures extent processing advances the logical block position
by checking `pos > old_pos` after processing the 3 extents in each iteration. Prevents infinite
loops from extent descriptors with zero or invalid block counts.

3. **Error handling improvement**: Changes return value check from `if (q == mda_end)` to
`if (q >= mda_end)` for safer bounds checking. Also ensures grub_errno is set when
grub_hfs_find_node() fails to find an extent record.
