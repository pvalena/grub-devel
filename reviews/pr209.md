## Additional findings

Feature is off by default (`--enable-fortify-source`). When off,
all annotations expand to nothing and the build is unchanged.
Allocators gain `alloc_size()` annotations so
`__builtin_dynamic_object_size` tracks malloc'd buffers into
subsequent copies. `kern/misc.c` and `minilib.c` correctly `#undef`
the fortified macros to prevent self-wrapping. `GRUB_OBJECT_SIZE0`
(whole object) used for mem* functions, `GRUB_OBJECT_SIZE`
(subobject) for string functions — matches glibc's split.
