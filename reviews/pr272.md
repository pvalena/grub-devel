## Additional findings

`loaded_image->image_base` is `void *` (matches `%p`), and `loaded_image->image_size` is
`grub_efi_uint64_t` (`include/grub/efi/api.h`); it is explicitly cast to `(unsigned long long)`
and printed with `%llx`, which is the platform-safe pattern (avoids the `sizeof(long)`-on-ILP32
pitfall this project has flagged elsewhere). `grub-core/kern/misc.c`'s format implementation
handles the `ll` length modifier (`LONGLONG`/`UNSIGNED_LONGLONG` cases), so `%llx` is a supported
conversion. This is a debug-output-only, additive change with no effect on control flow or the
existing `%p` starting-image message.
